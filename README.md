# Socio-Economic-Idea-Evaluator
Socio-Economic Idea Evaluator

## Usage

Run the evaluator with 0-10 scores for each criterion:

```bash
python evaluator.py --social-impact 8 --economic-feasibility 7 --inclusivity 9 --sustainability 8 --cost-efficiency 6
```

Output includes:
- overall score (0-10)
- rating band
